AES on the fast path

When both ends have AES hardware, the session uses AES-256-GCM: about a third of the time per packet of ChaCha20.

Big frames to the kernel

Consecutive TCP segments are merged before they reach the network stack, so the kernel works once per 64 KB, not once per packet.

Nothing in the way

Batched UDP, cached keys, a constant-time replay window and a shared clock keep each packet's path short.

    Everything a modern tunnel needs

    IPv4 and IPv6
    Inside the tunnel with NAT66, and as the connection itself. Clients never leak IPv6 when the server offers none.
    Flood shield
    WireGuard-style cookies keep the server answering real clients through a flood of 170,000 forged hellos a second.
    Self-healing
    Rekeys under full load without a dropped ping, and back within seconds after an outage or a network change.
    Per-client stealth keys
    Give each device its own key and revoke a lost one without touching the rest.
    Cover rotation
    Stealth clients move to a fresh connection every half hour or so, so one tunnel looks like a series of ordinary connections.
    Thoroughly tested
    98 unit and integration tests, plus 41 end-to-end checks that run real tunnels in Docker.

    Up and running in four steps

    Linux or macOS, with a recent Rust toolchain.

    1. Build

      cargo build --release
sudo install -m 755 target/release/lw /usr/local/bin/lw

    2. Make keys

      Once for the server and once for each client.

      lw gen-keys

    3. Start the server

      Put the keys in /etc/lw/lw0.toml, then run it directly or as a service.

      sudo systemctl enable --now lw@lw0

    4. Connect a client

      With transport = "auto", it switches to TLS on port 443 by itself when UDP is blocked.

      sudo lw up --config client.toml

    Built on the new standards

    ML-KEM-768 (FIPS 203) and ML-DSA-65 (FIPS 204) work alongside X25519, AES-256-GCM, XChaCha20-Poly1305 and BLAKE3, composed in the Noise IK pattern with a signed transcript. An independent audit is the next milestone on the roadmap.
